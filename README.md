首先光线从最左侧最上边的红点(z,y)出发，假设到达下一个表面高度仍为y，利用非球面的矢量高公式计算出y对应的z1，
z1与z做差，大于1e-12，不能满足条件，光线继续将从原点按照原方向矢量(uz, uy)前进，移动Δz/uz的比例时间，到达新的点假设交点(z1，y1)，
将y1替换原先的y，z1替换原先的z，接下来继续验证交点是否满足条件，将y1代入矢高公式，计算曲面上对应的z2，
z1与z2做差，大于1e-12，不能满足条件，继续按照方向矢量移动（返回）Δz‘，到达新的假设点，开始下一轮迭代
